Aurthayon logo
==============

Save the client's horizontal logo (green background + mark + "AURTHAYON" wordmark) here as:

  aurthayon-logo.png

Use a PNG with reasonable resolution (e.g. 800–1200px wide). The app shows it in the header; you can swap the file anytime without rebuilding if names match.

If the file is missing, the header shows a broken image until you add it.
